LaTeX rendering check

This page loads the real scripts/katex-render.js. If the formulas below are drawn as maths, the script works. If they stay as grey monospace TeX, it did not load — check the browser console.

1. Inline maths — what latex.ts emits

Sustained throughput follows $\frac{r_{max}}{1 + e^{-k(t - t_0)}}$ requests per second, where $r_{max}$ is the ceiling and $t_0$ the midpoint.

2. Display maths

$$\int_{0}^{T} r(t)\,dt = \frac{r_{max}}{k}\ln\left(1 + e^{k(T - t_0)}\right)$$

3. The braces that would have broken MDX

$\frac{a}{b}$, $x_{n}^{2}$, $\sqrt{2}$, $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$

4. Dollar signs in ordinary prose — must NOT be touched

5. HTML-encoded braces — what a platform may hand you
