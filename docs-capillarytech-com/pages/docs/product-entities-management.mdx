Create and manage your organization's SKUs, Brands, Categories, Attributes, Labels, and Collections from a single self-serve Products page.

A **Product** is an item your organization sells. You can add each product to the catalog with details such as its name, description, brand, category, price, and other characteristics.

A product can be identified by a **SKU**, described using a **Brand**, **Category**, and **Attributes**, and organized using **Labels** and **Collections**. See the [Key terms](/product-entities-management#key-terms) section below to understand how each of these terms relates to a product.

## Key terms

| **Term**                                                     | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **[SKU (Stock Keeping Unit)](#creating-and-editing-a-sku)**  | • A SKU is the unique code used to identify a specific version of a product. • For example, a blue shirt in size Medium and the same shirt in size Large are treated as two different SKUs. Each SKU represents one distinct version of a product and helps you track pricing, inventory, and variations accurately. • Every product in the system must have a unique SKU.                                                                        |
| **[Brand](#creating-and-editing-a-brand)**                   | • A brand represents the name or label associated with a product, such as Nike, Adidas, or Apple. Brands help you group products by manufacturer or label, and support reporting and organization. A brand can also be nested under a parent brand, for example, a sub-brand under its parent company. • For example, Nike can be the parent brand, with Jordan as its sub-brand.                                                                 |
| **[Category](#creating-and-editing-a-category)**             | • A category groups similar products together. Categories help you organize products and make them easier to search, filter, and report on. Categories support a parent-child hierarchy, so you can nest related categories under a broader one. • For example, Apparel can be the parent category, with Shirts, Trousers, and Jackets as child categories.                                                                                       |
| **[Attribute](#creating-an-attribute)**                      | • An attribute describes a characteristic of a product, such as Colour, Size, or Material. Attributes let you capture consistent, structured details about a SKU instead of free-text notes, • For example, a T-shirt SKU can have the attributes Colour = Red, Size = Medium, and Material = Cotton.                                                                                                                                             |
| **[Label](#creating-a-label)**                               | • A label is a tag you attach to a SKU to categorize or filter it. A label can have an expiry, so it automatically stops applying to a SKU after a set time instead of needing manual removal. • For example, you can assign the label "Summer Sale" to selected SKUs with an expiry date of 31 August. After that date, the label is automatically removed from those SKUs.                                                                      |
| **[Collection](#grouping-products-dynamically-collections)** | • A collection is a saved, rule-based group of SKUs. Unlike a manually maintained list, a collection's membership recalculates automatically on a schedule, so it always reflects which SKUs currently match its rules. • For example, you can create a collection that includes all SKUs in the Footwear category priced under 5,000. When a new footwear SKU is added with a price below 5,000, it is automatically included in the collection. |

## Creating a SKU

To create a SKU, follow these steps:

1. Navigate to **Entities** > **Products** > **SKUs**.

   <Image src="https://files.readme.io/3f7d3a1c698c449f23c3bfce1424865c1e2c05f4595cf5fc8017fc71a6c572d4-sku.gif" alt="Sku" caption=" " />

2. Select **+ New Product**.

3. Enter the **SKU code**, **Product name**, and **Description** (all required).

4. (Optional) Select **+ Add label**. i. Select an existing label from the **Label name** dropdown, or select **+ New label**. ii. If you select **+ New label**, a modal appears. Enter the label details. iii. Select **Expiry configuration** to define how long the label remains assigned to the product. If no expiry is configured, the label assignment defaults to **Never Expire**. iv. Select **Add Label**. The label is created and becomes available in the **Label name** dropdown.

<Image src="https://files.readme.io/40e03718108487e62911c1fed64b95f273466081a861d6e54e4590a186529943-adding_new_label_in_sku.gif" alt="Adding new label in sku" caption=" " />

5. Select a **Brand** and **Category** (both required). i. Select an existing brand or category from the respective dropdown, or search by name. ii. To create a new brand or category, select **+ New brand** or **+ New category**. iii. In the modal that appears, enter the required details. iv. Select **Add Brand** or **Add Category**. The new brand or category becomes available in the respective dropdown.
6. (Optional) Add one or more **Attributes** — an attribute plus its value, for example, Colour: Red.
7. (Optional)**&#x20;**&#x53;elect **Additional details** to set a **Price** and an image URL. For **Returnable**, choose **Yes** to enable the **Returnable days** field and type a number or use the arrows to set it, or **No** to leave it disabled.
8. Select **Add product**.

<Image src="https://files.readme.io/5c2956bfbfed6e0905c18ffe914fd682c0d762d50889c8caeca5085a99fbb7ec-creating_sku.gif" alt="Creating sku" caption=" " />

### Viewing and editing a SKU

To view or edit a SKU, follow these steps:

1. Navigate to **Entities** > **Products** > **SKUs**.
2. On the SKUs list, review each product's **Product name** and **SKU code**, **Labels**, **Brand**, **Category**, and when it was last updated. Select the **Product** **Name&#x20;**&#x63;olumn header to sort the SKU code alphabetically. Use **Search by code** to find a specific SKU.
3. Select a SKU to open its detail page, showing everything you set when creating it.
4. Select **Edit** to change any field, then select **Update product**.

   **Note:** The **SKU code** can't be changed after the SKU is created.

<Image src="https://files.readme.io/3f18ed439f29bbd8d361eed4d6fb0337d8298eda8dacadd3233d7febb59f1467-viewing_and_editing_sku_code.gif" alt="Viewing and editing sku code" caption=" " />

## Creating a brand

To create a brand, follow these steps:

1. Navigate to **Entities** > **Products** > **Brands**.
2. Select **+ New brand**.
3. Enter a **Brand Code** and **Brand Name** (both required).&#x20;
4. (Optional) Select a **Parent Brand&#x20;**&#x66;rom the dropdown and add a **Description**.
5. Select **Add Brand**.

<Image src="https://files.readme.io/37b22a8e4e46643b9e4333c2da9edab8367dc483ad761e9a1455dc580897548e-create_brand.gif" alt="Create brand" caption=" " />

### Viewing and editing a brand

To view or edit a brand, follow these steps:

1. Navigate to **Entities** > **Products** > **Brands**.
2. On the Brands list, review each brand's **Brand code** and **Brand name**, **Parent brand**, and when it was last updated. Select the **Brand** **code&#x20;**&#x63;olumn header to sort the **Brand name** alphabetically. Use **Search by brand code and name** to find a specific brand .
3. Select a brand to open its detail page. Review the **Basic info** section, then view the **Hierarchy** section, which shows the parent brand and any child brands.
4. (Optional) Select **Edit** to update the brand details. You can edit only the **Brand name** and **Description**. The **Brand code** and **Parent brand** cannot be edited. Select **Save**.

   The changes will be updated for that brand.

<Image src="https://files.readme.io/cad2ecf4da24d759888129fbe6ee2b598cea6087d2d606e6c6b275cfd5992aa6-viewing_and_editing.gif" alt="Viewing and editing" caption=" " />

## Creating a category

To create a category, follow these steps:

1. Navigate to **Entities** > **Products** > **Categories**.
2. Select **+ New category**.
3. Enter a **Name** and **Code**.&#x20;
4. (Optional) Select a **Parent category** from the dropdown to nest it under an existing category, and add a **Description**.
5. Select **Save changes**.

<Image src="https://files.readme.io/c2c4b43122ba9c92ae85309e44194f706e4baf70f81e6692fd71e5f6e89406ec-create_category.gif" alt="Create category" caption=" " />

### Viewing and editing a category

To view or edit a category, follow these steps:

1. Navigate to **Entities** > **Products** > **Categories**.
2. On the Categories list, review each category's **Category code**, **Category name**, **Parent category**, and **Last updated** details. Select the **Category name** column header to sort the **Category code** alphabetically. Use **Search by category code and name** to find a specific category.
3. Select a category to open its detail page. Review the **Basic info** section, then view the **Hierarchy** section, which shows the parent category and any child categories.
4. (Optional) Select **Edit** to update the category details. You can edit the **Category name** and **Description,** and **Parent category.&#x20;**&#x54;he **Category code** cannot be edited. Select **Save changes**.

## Creating a label

Labels let you tag SKUs for filtering and reporting, with an optional expiry.

To create a label, follow these steps:

1. Navigate to **Entities** > **Products** > **Labels**.
2. Select **+ Create Label**.
3. Enter an **External ID** and **Label Name** (both required), and an optional **Description**.
4. Set an **Expiry Configuration**:

   | Option                         | Behavior                                                   |
   | ------------------------------ | ---------------------------------------------------------- |
   | Never Expire                   | The label stays on the SKU indefinitely.                   |
   | Fixed Date                     | You choose a specific calendar date for it to expire.      |
   | Expire after X days            | The label expires a set number of days after it's applied. |
   | Expire at end of current month | The label expires on the last day of the current month.    |
   | Expire at end of current year  | The label expires on the last day of the current year.     |
5. Select **Add Label**.

<Image src="https://files.readme.io/86f3ed84405f70c51391c3873f72a098581006fc9c96ec5b1b5bb01a509a1483-label_product_view_edit.gif" alt="Label product view edit" caption=" " />

### Viewing and editing a label

To view or edit a label, follow these steps:

1. Navigate to **Entities** > **Products** > **Labels**.
2. On the Labels list, review each label's **Name**, **Status**, **External ID**, **Expiry configuration**, and **Last updated** details. Select the **Name** column header to sort labels alphabetically. Use **Search by label name and IDs** to find a specific label, or the **Status** filter to show only **Active** or **Deactivated** labels.
3. Select a label to open its detail page. Review the label details, including the **Label ID**, **External ID**, **Name**, **Status**, **Description**, and **Expiry configuration**.
4. (Optional) Select **Edit** to update the label details. You can edit the **External ID**, **Label name**, **Description**, and **Expiry configuration**. The **Label ID** cannot be edited. Select **Save Label**.

   The changes are saved for that label.  Use the **Status** filter above the list to switch between active and deactivated labels.

<Image src="https://files.readme.io/580243932f36d62ec064112f5061f9ca04ba9002ea2309572bbc598f6e257645-view_and_edit_labels.gif" alt="View and edit labels" caption=" " />

### Deactivating a label

To deactivate a label, follow these steps:

1. Navigate to **Entities** > **Products** > **Labels**.
2. Locate the label you want to deactivate, select the **three-dot menu**, and then select **Deactivate**.
3. In the confirmation dialog box, select **Yes, deactivate**.

The label is deactivated and appears in the **Labels** listing with the **Deactivated** status.

<Image src="https://files.readme.io/e2e34269941774bfa56298525f198d3942406bea6f3158d61fe445fa274055a4-deactivating_label.gif" alt="Deactivating label" caption=" " />

### Activating a label

To activate a deactivated label, follow these steps:

1. Navigate to **Entities** > **Products** > **Labels**.
2. On the **Labels** listing page, go to the **Status** filter and select **Deactivated**. This displays only the deactivated labels.
3. Locate the label you want to activate, select the **three-dot menu**, and then select **Activate**.
4. In the confirmation dialog box, select **Yes, activate**.

The label is activated and appears in the **Labels** listing with the **Activated** status.

<Image src="https://files.readme.io/d4eb6199244cc4d3fa23e9ba82ebbdfb77f674ee4aa982a085929b71f4bd564f-activating_label.gif" alt="Activating label" caption=" " />

## Grouping products dynamically (collections)

Collections are rule-based groups of SKUs that stay up to date automatically, instead of a static list you maintain by hand, for example, "all SKUs in the Footwear category priced under 5,000."

To create a collection, follow these steps:

1. Go to **Entities** > **Products** > **Collections**.
2. Select **+ Create Collection**.
3. Enter a **Collection name** and, optionally, an **External ID** and **Description**.
4. Choose how often membership recalculates under **Refresh frequency**.
5. Under **Membership criteria**, choose whether condition blocks must all match (**AND**) or whether any can match (**OR**). Within each block, select **+ Add condition** to add an attribute, operator, and value. Select **+ Add condition block** to add another block.
6. Select **Save collection**.

Once created, select a collection to see its read-only detail view, including its membership criteria and an audit log of when it was created, edited, and last recalculated.
