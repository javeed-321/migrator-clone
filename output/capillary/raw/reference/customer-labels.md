# Customer Labels

Customer labels are used for tagging customers based on their activities or loyalty histories. Tags are used in loyalty, campaigns and Essential Insights. You can add new labels and tag labels to customers using APIs of organization and customers mentioned here.

<br />

> **Warning:** These APIs are deprecated and have been superseded by the <Anchor target="_blank" href="https://docs.capillarytech.com/reference/labels">new label APIs</Anchor>. Please refer to the new label APIs documentation for current usage.

| Code  | Description                     |
| ----- | ------------------------------- |
| 33000 | {x} label not found             |
| 33001 | User labels not found           |
| 33002 | Org labels not found            |
| 33003 | Label {x} already exists in org |
| 33004 | Org max Label config not set    |
| 33005 | Org max Label count exceed      |
| 33006 | Org labels empty post payload   |
