# Create RCS Template

RCS templates help you design visually engaging and interactive messages that enhance customer communication. Once your RCS account is configured for your brand, you can start creating RCS message templates directly in Engage+.

# Create RCS template

To create an RCS template follow the given steps:

1. On the **Engage+** homepage select **Creatives** tab.
2. Navigate to the RCS engagement channel. You can view the list of existing templates. You can either use one of the available templates or select **Create new** to create a template from scratch.

<Image src="https://files.readme.io/f881df0541a09c4454f7d23731c9c46dfbcea3c25f23808f32094f82dd2ed9e8-Screenshot_2025-11-10_at_11.51.59_AM.png" align="center" width="75% " border={true} />

<Callout icon="📘" theme="info">
  ### Note

  To duplicate an existing template instead of creating one from scratch, navigate to **Creatives** > **RCS** tab, select the desired template, click the more options icon (**...**), and then select **Duplicate**.
</Callout>

3. A modal appears to create the RCS template. In the **Creative name** section enter a name for the template.

<Image src="https://files.readme.io/b125f86f02c08dd11357c476a2469e69846a5afc968cc269637bdad252e3c94d-Screenshot_2025-11-10_at_2.31.43_PM.png" align="center" width="60% " border={true} />

4. In **Template Type**, choose the desired media type. You can create either a Text Message or a Rich Card template.

a. **Text Message**

* Select Text message to create a plain text message.
* In the Text message field, enter the message content.  To personalize the message, click +Add variables and select the desired variables. The message length is limited to 160 characters.

  <Image src="https://files.readme.io/c32e500df7e0baadff4a59e30469252d8835e69e97abc4515112d72dc22888cb-Screenshot_2025-11-10_at_2.33.30_PM.png" align="center" width="60% " border={true} />

b. **Rich Card**

* Select Rich card to create an image or video/ slideshow based message. You can upload media files from your local system or Gallery.

  * **Image**

    1. Select the **image and card orientation** from the Image and Card Orientation dropdown.

       | Orientation Name                    | Description                                                                       |
       | :---------------------------------- | :-------------------------------------------------------------------------------- |
       | **Vertical Short**                  | Displays the media in a compact vertical layout.                                  |
       | **Vertical Medium**                 | Displays the media in a taller vertical layout, providing more space for content. |
       | **Horizontal – Media to the left**  | Displays the media on the left side in a horizontal layout.                       |
       | **Horizontal – Media to the right** | Displays the media on the right side in a horizontal layout.                      |
    2. Upload the image from your local system or gallery.
    3. In **Title**, enter a title for the template. You can add variables by selecting **+Add variables**. The maximum character limit is 200, and a live preview of the title appears on the right side.
    4. In **Text message**, enter the message content. You can add variables by selecting **+Add variables**. The maximum character limit is 2000, and a live preview of the text message appears on the right side.

       <Image src="https://files.readme.io/a4beccca58fb55acaad3b6b778ffab72e24a603ad293bc57328932ecb2570b5b-gif_.gif" align="center" width="70% " border={true} />

  * **Video**

    1. Select the **card orientation** from the Card Orientation dropdown.

       | Orientation Name                    | Description                                                                       |
       | :---------------------------------- | :-------------------------------------------------------------------------------- |
       | **Vertical Short**                  | Displays the media in a compact vertical layout.                                  |
       | **Vertical Medium**                 | Displays the media in a taller vertical layout, providing more space for content. |
       | **Horizontal – Media to the left**  | Displays the media on the left side in a horizontal layout.                       |
       | **Horizontal – Media to the right** | Displays the media on the right side in a horizontal layout.                      |
    2. Upload the video file (MP4 format) with a maximum size of 10 MB.
    3. Upload a **thumbnail** for the video in JPEG, JPG, or PNG format, with recommended dimensions up to 770 × 335 px and size between 40 KB and 100 KB.
    4. In **Title**, enter a title for the template. You can add variables by selecting +Add variables. The maximum character limit is 200, and a live preview of the title appears on the right side.
    5. In **Text message**, enter the message content. You can add variables by selecting +Add variables. The maximum character limit is 2000, and a live preview of the text message appears on the right side.

       <Image src="https://files.readme.io/ad1f8b4dadec7fa752e6f73c8ad8d3517a17eaa51a9080d462fb404f40d88275-gif__1.gif" align="center" width="70% " border={true} />

c. **Carousel**

* Select **Carousel** to create a message with multiple content cards that customers can swipe through. Each card can have its own media, title, description, and buttons.

* Choose a **Card height** (**Short** or **Medium**) and **Card width** (**Small** or **Medium**) for the carousel. This sets the recommended image size for every card in the carousel:

  | Card height | Card width | Recommended image size |
  | :---------- | :--------- | :--------------------- |
  | Short       | Small      | 1160 × 720 px          |
  | Short       | Medium     | 1800 × 720 px          |
  | Medium      | Small      | 770 × 720 px           |
  | Medium      | Medium     | 1280 × 720 px          |

* A carousel starts with one card and supports up to **10 cards**. Select **+ Add card** to add another card. You must finish and save the current card before you can add the next one. At least one card must always remain in the carousel, so the delete option is disabled when only one card is left.

* For each card:

  1. Select the **Media type** - **Image** or **Video**.
     * **Image**: Upload a PNG, JPG, JPEG, or GIF file up to 2 MB.
     * **Video**: Upload an MP4 file up to 5 MB. The video dimensions must match the selected Card height and Card width. Also upload a thumbnail image (JPG, JPEG, or PNG) with dimensions of up to 480 × 448 px and a file size between 40 KB and 100 KB.
  2. In the **Card title**, enter a title for the card. You can add variables by selecting **+Add labels**.
  3. In the text message field, enter the card's description. You can add variables the same way.
  4. In **Buttons**, you can add up to 4 buttons for the card (see step 5 below for button types). The first card always keeps at least one button, while buttons on the remaining cards are optional.

  <Image src="https://files.readme.io/741b932fca3fbb1d19fb576e0fad1607dd8af9ddb49829f97cfbf2f3af74f868-rcs_caraosel.gif" border={true} />

<Callout icon="📘" theme="info">
  ### Note

  The first card in a carousel always keeps at least one saved button, it can't be removed.
</Callout>

5. In the **Buttons** section, select the **edit** or **+Add button** icon to add a CTA. Choose a **Button type** — **Phone number**, **URL**, or **Quick reply**, then enter the button text. This is a mandatory step.

   * If you choose **URL**, also select a **URL type**: **Static** (a fixed link) or **Dynamic** (a link built from a variable, resolved when the message is sent), then enter the URL.

<Image src="https://files.readme.io/504d7d2a9f68d9bb8a906d465c79b012f31b7fbd17574cbe741f028e417b9cd0-gif__2.gif" align="center" width="70% " border={true} />

6. (Optional) Add a **Fallback SMS message**. This sends the template as an SMS to customers whose device doesn't support RCS.

   1. Navigate to the **Fallback SMS message (Optional)** section and select **Select template**.
   2. In the **Creative templates** panel, choose an existing SMS template. If your organization is **not DLT-enabled**, select **Create new** to create a new SMS template. If your organization is **DLT-enabled**, select **Upload template** to upload a DLT-approved SMS template.
   3. Edit the SMS content and map any variables, you can use preview and test to preview the message contnet and test it then select **Save**. The panel closes, and the selected template appears as a card showing its name and a message preview.
   4. In the Fallback message section, select the More (⋮) menu. Choose **Edit** to update the fallback message template, or select **Remove** to detach it from the RCS template.

      <Image src="https://files.readme.io/d550e4e10a156f82dafd8b7c9c715f01011e463ac01a691874dc463b3ebb24bc-sms_fallback.gif" border={true} />

<Callout icon="📘" theme="info">
  ### Note

  Fallback SMS is optional. If you skip it, customers whose devices don't support RCS won't receive any message for this template.
</Callout>

7. Select **Send for approval**. The vendor reviews and approves the template within 24 hours. Once approved, the template appears on the RCS Templates page with the status **Approved**. If the template is rejected, its status will be shown as **Rejected**.

<Image src="https://files.readme.io/276dcc944008c23d80a5b07f1564e9821b93aaabff3e56f00a253346cf6bde52-Screenshot_2025-11-10_at_2.52.50_PM.png" align="center" width="70% " border={true} />

<Callout icon="📘" theme="info">
  ### Note

  To delete an existing template, on the **Creatives**> **RCS** tab > Navigate to the respective template > Click more options (...) > Click **Delete**.
</Callout>
